Project Folder Structure

staff/
Contains all speaker, panelist, keynote, committee member, and organizer photographs displayed throughout the conference website.

logos/
Contains all official FEW-AI branding assets, including:
- FEW-AI logos
- Committee and supporter logos
- Venue/location map images
- Other static visual identity resources used across the website

profiles/
Contains the individual HTML profile pages for speakers and panelists.
These pages include:
- Biography (Biosketch)
- Affiliation
- Research interests
- Personal website links
- Presentation information

The profile pages are linked from the "Panel" and "Keynote" sections of the conference website.

gallery/
Contains all conference photographs displayed in the Photo and Gallery sections of the website.

pdf/
Contains downloadable conference documents such as:
- Posters
- Proceedings
- Program booklets
- Additional conference materials

Root HTML Files

index.html
Main conference homepage.

comitee.html
Workshop committee information and organizational structure.

program.html
Conference schedule and agenda.

keynote.html
Keynote speaker information and presentation details.

panel.html
Panel discussion information and links to panelist profile pages.

poster.html
Poster session and poster download links.

photo.html
Timeline-based conference photo view.

photo_gallery.html
Grid/gallery view of conference photographs.
